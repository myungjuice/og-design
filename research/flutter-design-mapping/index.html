1.0

HTML 토큰을 Flutter 타입으로 변환

색상값을 화면마다 복사하지 않고 의미 기반 토큰으로 옮깁니다. Primary 후보가 바뀌어도 Theme 한 곳을 수정하면 두 앱의 공통 스타일에 반영되는 구조입니다.

Surface · Ink · RuleColorSchemesurface·onSurface·outline·outlineVariant로 매핑해 카드, 구분선, 배경 대비를 통일합니다.

2.0

ThemeData에서 기본 형태와 상태를 연결

현재 두 앱의 ThemeData에는 ColorScheme·AppBar·폰트만 정의되어 있습니다. Flutter 기본 위젯을 활용할 수 있는 요소는 별도 위젯을 만들기 전에 컴포넌트 테마로 흡수합니다.

BUTTONS & INPUTS

기본 위젯 테마

  • FilledButtonThemeData · OutlinedButtonThemeData · TextButtonThemeData
  • InputDecorationTheme으로 레이블·도움말·오류 상태 통일
  • 비활성·포커스·선택 상태는 WidgetStateProperty로 연결
SELECTION

선택 컨트롤 테마

  • CheckboxThemeData · RadioThemeData · SwitchThemeData
  • TabBarThemeData · ChipThemeData
  • 색상뿐 아니라 테두리와 표시 형태를 함께 사용해 상태 구분
SURFACES

기본 표면 테마

  • AppBarTheme의 기존 동작을 유지하며 타이틀과 아이콘 규격 보강
  • CardThemeData · DividerThemeData
  • 화면 배경과 카드 표면의 단계가 일관되게 보이도록 구성
OVERLAYS

기본 오버레이 테마

  • BottomSheetThemeData · DialogThemeData
  • SnackBarThemeData · ProgressIndicatorThemeData
  • 동작은 유지하고 반경·여백·색상·텍스트 기준을 공통 적용
3.0

공통 규격과 앱별 기능을 분리

유저앱과 점주앱은 독립된 Flutter 프로젝트입니다. 디자인 기준은 공유하되 기능과 화면 구조까지 억지로 하나의 위젯으로 묶지 않습니다.

SHARED

두 앱 공통

컬러·타입·간격·모서리·아이콘 의미, 버튼·입력·선택 상태, 앱바·다이얼로그·바텀시트·스낵바의 시각 규칙을 공유합니다.

USER APP

유저앱 전용

중앙 바코드를 포함한 하단 5탭, Q오더·퀵적립 전역 액션, 마일리지·매장·이벤트·커뮤니티 카드 구조를 별도로 둡니다.

STORE APP

점주앱 전용

매장 운영 흐름, 예약·웨이팅·Q오더 상태 카드와 점주용 내비게이션은 공통 토큰을 사용하되 독립 컴포넌트로 유지합니다.

초기에는 앱별 어댑터가 안전합니다

두 앱에 같은 Theme·토큰 규격을 각각 적용해 리뉴얼 위험을 낮춥니다. 양쪽에서 실제로 안정된 기본 요소가 확인된 뒤에만 별도 로컬 패키지로 추출하는 방식을 검토합니다.

4.0

전역에서 화면 순서로 점진 적용

한 번에 전체 화면을 교체하지 않고 영향 범위가 넓고 재사용성이 높은 순서로 적용합니다. 기능 로직과 API 호출은 유지합니다.

01Foundation

ColorScheme·TextTheme·ThemeExtension을 유저앱과 점주앱에 동일 규격으로 정의합니다.

02Primitive

버튼·입력·선택 컨트롤·앱바처럼 Flutter Theme로 처리 가능한 기본 요소를 연결합니다.

03Pattern

다이얼로그·바텀시트·피드백·카드·목록 등 구조가 필요한 공통 패턴을 앱별 래퍼로 적용합니다.

04User Screens

10~11월 리뉴얼 순서에 맞춰 유저앱 화면을 전환하고 기존 기능 회귀 테스트를 병행합니다.

05Store Alignment

점주앱은 공통 토큰과 기본 컴포넌트를 우선 반영하고 업무 화면은 별도 일정으로 순차 전환합니다.

5.0

디자인 일관성과 기존 동작을 함께 검증

HTML과 픽셀을 그대로 복제하는 것보다 같은 토큰·상태·정보 위계를 유지하는지가 중요합니다.

적용 완료 기준

  • Primary 변경이 개별 화면 수정 없이 공통 Theme를 통해 반영됩니다.
  • 텍스트 스타일과 간격에 화면별 임의값을 추가하지 않습니다.
  • 버튼·입력·선택 요소의 기본·포커스·비활성·오류 상태가 동일합니다.
  • 유저앱과 점주앱의 공통 요소는 같은 의미와 시각 규칙을 사용합니다.
  • 기존 로그인·적립·바코드·주문·예약 흐름의 동작이 유지됩니다.
  • 접근성 글자 크기, 터치 영역, 대비와 iOS·Android 표시를 확인합니다.
