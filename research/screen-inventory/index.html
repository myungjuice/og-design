Renewal Screen Inventory

화면과 개발 범위

리뉴얼 기획서와 현재 Flutter 유저앱 코드를 함께 대조해 화면, 모달, 스캔·적립 흐름과 공통 상태까지 분류했습니다.

디자인 적용 범위

기획서에 직접 포함된 화면과 기존 앱에만 존재하는 화면을 구분합니다. 화면 수가 늘어나도 같은 기준으로 범위를 판단합니다.

A · 전면 개편

리뉴얼 기획서에서 구조나 기능 변경이 명시된 화면입니다.

B · 시스템 적용

기존 동작은 유지하고 컬러·타입·간격·컴포넌트를 맞출 화면입니다.

C · 확인 필요

현재 운영 여부나 신규 기능과의 관계를 확인한 뒤 범위를 정할 화면입니다.

제외 · 대체 예정

새 화면으로 대체되거나 운영 종료가 확정된 기존 화면입니다.

코드 조사 기준

0_pages 아래 Dart 파일 102개를 기준으로 확인했습니다. 이 중 Scaffold를 포함한 파일은 62개이며, 다이얼로그·시트가 포함된 파일은 16개입니다. 파일 수는 화면 수와 같지 않으며 상태 화면과 분기까지 포함하면 실제 디자인 대상은 더 많습니다.

공통 상태

로딩, 데이터 없음, 오류, 성공, 권한 요청, 확인 다이얼로그와 스낵바는 개별 화면이 아니라 재사용 상태 패턴으로 관리합니다.

확정 기준과 확인 사항

현재까지 정해진 적용 원칙과 실제 화면 디자인 전에 확인할 항목입니다.

내 정보 바텀시트

기획서는 바텀시트 8종을 제시하면서 마일리지 내역을 별도로 설명합니다. 마일리지 내역을 8종에 포함할지 별도 시트로 둘지 최종 확인이 필요합니다.

홈 하단 리스트 카드

오픈일과 리뷰 키워드가 있는 하단 리스트 카드는 권장안으로 표현되어 있어 현재 확정 화면 목록에서는 제외했습니다.

프로필 캐릭터

3종 캐릭터 선택은 1차 범위에 포함하고, 의상·얼굴·액세서리 등 파츠 꾸미기는 후속 범위로 분리합니다.

지도 하단 시트

주변 매장, 마일리지, 바코드 시트의 열림 방식은 유지하고 디자인 시스템만 적용합니다.

플로팅 버튼

Q오더와 퀵적립 버튼은 주요 화면에 함께 노출하는 전제로 배치와 겹침 방지 규칙을 설계합니다.

누락 화면

기획서에 없는 기존 운영 화면도 최소한 컬러, 타이포그래피, 간격과 공통 상태 기준을 적용합니다.

아이콘

새 아이콘 세트를 확정하기 전까지 기존 아이콘 유지 기준으로 화면 시안을 진행합니다.
