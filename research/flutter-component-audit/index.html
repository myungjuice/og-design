구조 변경

신규 개발

현재 코드에 대응 요소가 없거나 리뉴얼 기획에서 새로 추가되는 컴포넌트입니다.

현재 공통 기반

두 앱은 같은 Flutter 기반을 사용하지만 디자인 시스템은 전역 테마보다 각 화면의 직접 스타일 지정에 더 많이 의존하고 있습니다.

FOUNDATION

Material 3 + Pretendard

두 앱 모두 Material 3와 Pretendard를 사용하며 375 × 812 기준의 화면 스케일을 적용합니다. 플랫폼 전환 애니메이션도 같은 방식입니다.

THEME

전역 테마 범위가 제한적

ThemeData에는 ColorScheme, AppBar, 폰트가 중심이며 버튼·입력·스위치·칩 테마는 별도로 정의되어 있지 않습니다.

DUPLICATION

같은 위젯이 앱별로 분리

같은 경로로 대응되는 위젯 파일 14개 중 3개만 완전히 동일합니다. 공통 명칭은 있지만 코드 수준에서는 각각 관리되고 있습니다.

컴포넌트별 판정

사용 횟수는 Flutter 생성자 호출을 기준으로 집계했으며, 스타일 헬퍼 호출은 제외했습니다.

Flutter 적용 원칙

두 앱이 같은 디자인 언어를 유지하면서도 현재 코드 구조를 한 번에 크게 바꾸지 않는 순서입니다.

01디자인 기준은 공통으로 정의

컬러·타이포그래피·간격·모서리·상태 명칭은 두 앱에서 같은 토큰과 규칙을 사용합니다.

02코드 적용은 앱별로 시작

현재 두 앱이 독립 Flutter 프로젝트이므로 초기에는 같은 규격을 각각 적용하고, 물리적인 공통 패키지 분리는 후속 판단으로 남깁니다.

03전역 테마부터 연결

AppBar·버튼·입력·선택 컨트롤처럼 사용 범위가 넓은 요소를 ThemeData에 먼저 연결합니다.

04기능 컴포넌트는 화면 설계 후 제작

캐릭터·마이랜드·커뮤니티처럼 리뉴얼에서 새로 생기는 요소는 화면 컨셉 확정 후 공통 기본 컴포넌트를 조합해 만듭니다.
