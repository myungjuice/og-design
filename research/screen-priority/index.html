화면 제작 우선순위

먼저 만든 화면의 규칙을 다음 화면에서 재사용할 수 있도록 순서를 정했습니다. 월별 개발 일정이 아니라 디자인 제작 순서입니다.

Priority 01기준 확정

공통 구조와 대표 화면

앱 전체에 반복될 기본 규칙과 메인 탭의 밀도·정보 위계를 먼저 결정합니다.

  • 앱바
  • 하단 탭
  • Q오더·퀵적립
  • 홈
  • 내 정보
Priority 02리뉴얼 핵심

11월 신규·전면 개편 화면

리뉴얼의 변화가 가장 크게 드러나는 메인 화면과 신규 콘텐츠 구조를 제작합니다.

  • 마이랜드
  • 바코드
  • 오지파크
  • 이벤트
  • 공모전
  • 커뮤니티
Priority 03핵심 흐름

사용·적립·주문과 주요 상세

거래와 적립처럼 오류·로딩·결과 상태가 많은 흐름에 확정된 컴포넌트를 적용합니다.

  • 마일리지 사용
  • 영수증 적립
  • Q오더
  • 매장 상세
  • 로그인·가입
Priority 04전체 확장

운영 화면과 예외 상태

기획서 밖의 기존 화면과 하위 상세까지 디자인 시스템 적용을 마무리합니다.

  • 예약·웨이팅
  • 공지·알림
  • 문의·정책
  • 권한 화면
  • 빈 상태·오류
Priority 05후속 제작

12월 게임 화면

티켓과 보상 정책을 반영해 게임 전용 화면과 결과 상태를 제작합니다.

  • 룰렛
  • 퍼즐
  • 티켓 차감
  • 보상 결과
  • 참여 제한

현재 적용 원칙

컨셉 결정 전에도 바뀌지 않는 기준입니다.

컬러 토큰

OG Indigo를 임시 기준으로 사용하며 Primary 값이 변경되면 전체 시안에 함께 반영합니다.

아이콘

아이콘 체계가 결정되기 전까지 기존 Material 아이콘과 현재 자산을 유지합니다.

지도 하단 시트

열리는 방식은 유지하고 컬러, 타이포그래피, 카드와 간격을 개편합니다.

프로필

기존 Multiavatar·사진 설정은 신규 캐릭터 3종 선택 화면으로 대체합니다.
