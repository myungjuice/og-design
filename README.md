# OGGO Design

오지고랜드 유저앱 UI/UX 리뉴얼을 위한 디자인 시스템과 화면 시안을 관리합니다.

## Structure

- `docs/planning`: 리뉴얼 기획 문서
- `design-system/foundations`: 컬러·타이포그래피·간격 기준
- `design-system/components`: 공통 UI 컴포넌트
- `concepts`: 방향 선택을 위한 컨셉 시안
- `screens`: 탭별 최종 화면 시안
- `assets`: 브랜드·아이콘·캐릭터 자산
- `reports`: 일정 및 공유용 자료
