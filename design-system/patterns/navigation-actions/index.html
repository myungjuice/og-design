앱바

메인 화면과 하위 화면 모두 같은 높이와 정렬 규칙을 사용합니다. 뒤로가기나 우측 액션이 없어도 제목의 중앙 위치는 유지합니다.

좌우 액션

아이콘 크기와 관계없이 누를 수 있는 영역은 최소 48×48dp를 확보합니다.

제목

18sp·700 중앙 정렬을 유지하며 한 줄을 넘으면 말줄임 처리합니다.

아이콘

새 아이콘 체계가 결정되기 전까지 현재 Material 아이콘을 사용합니다.

하단 5탭과 전역 버튼

중앙 바코드는 현재처럼 강조하고, Q오더는 왼쪽, 퀵적립은 오른쪽에 같은 크기로 배치합니다. 실제 자산은 유지하되 배치 규칙을 먼저 통일합니다.

메인 화면 배치

하단 바

현행 83dp와 Safe Area 대응을 유지하고 5개 탭을 같은 폭으로 배치합니다.

중앙 바코드

62dp 강조 영역을 유지하며 선택 상태와 관계없이 주요 액션으로 인지되게 합니다.

Q오더·퀵적립

현행 기준 58dp, 화면 좌우 16dp, 하단 바 위 동일한 높이로 정렬합니다.

Safe Area

기기 하단 영역만큼 하단 바와 플로팅 버튼을 함께 위로 이동합니다.

노출 기준

전역 버튼이 주요 화면에서는 항상 보이되, 촬영·스캔·인증·거래처럼 집중이 필요한 흐름을 가리지 않도록 구분합니다.

화면 유형하단 탭Q오더·퀵적립적용 기준
5개 메인 탭노출둘 다 노출홈·마이랜드·바코드·오지파크·내 정보의 기본 상태입니다.
지도 하단 시트노출겹침 확인시트 높이에 따라 버튼이 콘텐츠나 드래그 핸들을 가리지 않게 이동합니다.
매장 상세 패널노출둘 다 노출현재 홈 위에 표시되는 구조를 유지하는 전제입니다.
일반 하위 화면숨김숨김앱바와 뒤로가기를 사용하는 목록·상세·입력 화면입니다.
카메라·QR 스캔숨김숨김촬영 영역과 스캔 가이드를 가리지 않도록 모든 전역 요소를 숨깁니다.
로그인·회원가입·권한숨김숨김앱 진입 전 흐름에는 서비스 전역 액션을 표시하지 않습니다.
거래 확인·처리·결과숨김숨김마일리지 사용과 Q오더 처리 도중 중복 진입을 막습니다.

배치·동작 규칙

시각 컨셉 확정 후 모서리와 색상은 바뀔 수 있지만 아래 구조는 유지합니다.

좌우 대칭

Q오더와 퀵적립은 동일 크기와 동일한 하단 기준선을 사용합니다.

콘텐츠 보호

스크롤 콘텐츠의 마지막 항목에는 하단 바와 전역 버튼 높이만큼 여백을 확보합니다.

시트 충돌

지도 시트가 확장되면 버튼을 시트 위로 이동하거나 시트가 버튼 아래에서 멈추게 합니다.

연속 실행 방지

액션을 누른 직후에는 중복 탭을 막고 다음 화면이 열리면 버튼을 숨깁니다.

상태 복귀

하위 흐름을 종료하면 이전 메인 화면의 탭 선택과 스크롤 상태를 유지합니다.

접근성

표시 자산의 크기와 별개로 모든 아이콘과 플로팅 버튼에 최소 48×48dp 터치 영역을 제공합니다.
