공통 피드백 상태

화면마다 다른 이미지와 문구를 새로 만들지 않고 같은 구조에 상황별 콘텐츠를 적용합니다.

불러오는 중

inbox

error_outline

불러오지 못했습니다

원인을 길게 노출하지 않고 다시 시도할 방법을 제공합니다.

check

적립이 완료되었습니다

마일리지 변화와 다음 이동을 결과 화면에서 확인합니다.

location_on

권한이 필요한 이유를 먼저 설명한 뒤 시스템 설정으로 연결합니다.

info

문구·동작 원칙

화면 컨셉과 관계없이 유지할 공통 기준입니다.

오류 원문 제한

서버 응답이나 예외 전문을 그대로 보여주지 않고 사용자가 이해할 수 있는 원인과 행동으로 바꿉니다.

한국어 액션 통일

현재 일부 오류 스낵바의 `Close`를 `닫기`로 통일합니다.

중복 피드백 금지

같은 결과에 다이얼로그와 스낵바를 동시에 표시하지 않습니다.

거래 결과 유지

적립·사용·주문 결과는 자동으로 사라지는 스낵바만 사용하지 않습니다.

빈 상태 자산

네트워크 이미지에만 의존하지 않고 앱에 포함된 아이콘·일러스트 또는 텍스트 구조를 사용합니다.

접근성

모달이 열리면 포커스를 내부에 유지하고 닫힌 뒤 실행한 요소로 돌려보냅니다.
