제목

18sp·700을 기본으로 사용하고 화면 제목보다 한 단계 낮게 구성합니다.

우측 액션

‘전체 보기’, ‘내역 보기’처럼 목적지가 명확한 동사형 문구를 사용합니다.

보조 설명

필요한 경우에만 제목 아래 한 줄로 표시하며 반복 설명은 생략합니다.

값 비교

비교 대상은 같은 행과 같은 타이포 위계로 배치합니다.

빈 값

확인할 값이 없으면 0과 —를 의미에 맞게 구분합니다.

메뉴 리스트와 바로가기

텍스트 중심 메뉴는 하나의 리스트로 묶고, 자주 쓰는 기능을 빠르게 구분해야 할 때만 아이콘 그리드를 사용합니다.

목록형·그리드형

목록형

메뉴 수가 많거나 문구가 긴 경우 한 행씩 배치하고 구분선으로 묶습니다.

그리드형

동일한 중요도의 대표 메뉴 4~6개에 사용하며 2×3 또는 3×2로 구성합니다.

정렬

그리드형은 아이콘과 텍스트를 수평·수직 중앙에 배치합니다.

행 높이

목록 행은 최소 60dp, 전체 터치 영역은 최소 48dp를 확보합니다.

중첩 금지

하나의 카드 안에서 목록형과 그리드형을 동시에 사용하지 않습니다.

매장·이벤트·게시글

콘텐츠 성격에 따라 목록 카드와 피드 카드를 구분합니다. 모든 정보를 하나의 카드 형태로 강제하지 않습니다.

목록에서 판단에 필요한 내용만 두 줄까지 보여주고 상세 정보는 다음 화면에서 제공합니다.

매장 카드

썸네일·매장명·거리 또는 방문 정보·현재 가능한 행동을 우선합니다.

피드 카드

이미지·상태·출처·제목·요약 순서로 구성하고 상세 데이터는 목록에서 줄입니다.

상태 배지

NEW, 진행 중, 심사 중처럼 빠르게 판단해야 하는 상태에만 사용합니다.

전체 카드 탭

카드 전체가 하나의 상세 화면으로 이동할 때만 전체 영역을 탭 대상으로 사용합니다.

구조 선택 기준

콘텐츠를 카드로 감쌀지, 목록으로 이어갈지 판단하는 기준입니다.

공통 적용 원칙

컨셉 확정 후 색상과 모서리는 조정할 수 있지만 콘텐츠 위계는 유지합니다.

카드 남용 방지

모든 항목에 개별 배경과 그림자를 주지 않고 같은 맥락의 항목은 하나의 표면 안에 묶습니다.

한 카드·한 목적

카드 내부에 서로 다른 주요 이동 버튼을 여러 개 배치하지 않습니다.

고정 간격

화면 좌우 16dp, 카드 내부 16dp를 기본으로 하고 정보량에 따라 20·24dp 단계를 사용합니다.

상태 공간 유지

로딩·빈 상태·오류로 바뀌어도 섹션 제목과 화면 골격이 크게 움직이지 않게 합니다.

텍스트 제한

목록 제목은 한 줄, 설명은 최대 두 줄을 기본으로 하며 전체 내용은 상세 화면에서 제공합니다.

접근성

카드 전체가 눌리는 경우 의미 있는 접근성 라벨을 제공하고 내부 장식 아이콘은 읽기에서 제외합니다.
