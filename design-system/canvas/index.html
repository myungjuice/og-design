그라데이션

각도는 CSS 기준입니다. 0°는 위, 90°는 오른쪽, 180°는 아래 방향입니다. 색상 위치는 시작점 0%부터 끝점 100%까지입니다.

브랜드 그라데이션은 게이지·주요 브랜드 요소에, 금액용은 흰 카드 위 사용 가능 금액에 사용합니다. 작은 설명 글자나 오류 안내에는 사용하지 않습니다.
