# 디자인 캔버스

캔버스 선택은 `?canvas=foundations|components|explore|store|my-info`로 구분합니다.
기존 `#페이지-ID` 링크는 소속 캔버스로 자동 연결됩니다.

- `catalog.mjs`: 캔버스·페이지 목록과 소속. 새 페이지는 여기에 등록해야 전체 검토 목록에도 나타납니다.
- `boot.js`: 선택한 캔버스의 예시 모듈만 로드합니다. 캔버스 간 이동은 문서 전환으로 이전 DOM을 해제합니다.
- `area-layout.js`: 현재 캔버스의 배경·배치. 기본 스타일/컴포넌트는 격자, 페이지 계열은 기존 순서대로 4열 배치합니다. 각 행의 위쪽을 맞추고 가장 긴 페이지 아래에서 다음 행을 시작합니다.
- `home.js`: 홈·탐색과 매장 상세를 같은 렌더러 목록에서 선택해 생성합니다.
- `review.js`: 전체 목록은 메타데이터로 유지하고, 현재 화면에만 검토 컨트롤을 붙입니다. 검토 상태 저장 키는 기존 것을 유지합니다.
- `session.mjs`, `canvas.js`: 선택한 캔버스와 캔버스별 확대율·위치를 기억합니다. 분리 전 좌표는 배치 기준이 달라 새 좌표에 적용하지 않습니다.

페이지/컴포넌트 렌더러와 토큰 CSS는 기존 공통 원본을 계속 사용합니다. 캔버스마다 복제하지 않습니다.
공통 캔버스 모듈의 캐시 버전을 변경할 때는 모든 import에 같은 버전을 적용해야 중복 초기화를 피할 수 있습니다.

검증: `catalog.test.mjs`(목록·라우팅), `partitions.test.cjs`(선택 렌더링·전체 검토·프롬프트·위치 기억), `layout.test.cjs`(영역·겹침), `performance.test.cjs`(드래그), `view-state.test.cjs`(새로고침).
