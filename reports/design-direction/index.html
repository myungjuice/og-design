Design Direction Brief

오지고랜드 앱 리뉴얼 디자인 방향 제안

9월 디자인 작업의 첫 단계로 유저앱과 점주앱이 함께 사용할 컬러 기준을 제안하고, 리뉴얼 대표 화면인 내 정보를 다섯 가지 방향으로 비교했습니다.

Primary CandidatesBlue · Indigo · Violet

Current Working ColorOG Indigo
01 / COLOR

Primary 컬러 후보

로고의 Blue–Violet 계열을 기준으로 세 후보를 구성했습니다. 최종 선택 전 작업에는 브랜드와 기능의 균형이 좋은 OG Indigo를 임시 기준으로 사용합니다.

OG Blue

명확하고 기능적인 인상이 강한 방향입니다.

OG Indigo 현재 적용

브랜드 인지도와 서비스 기능의 균형을 맞춘 방향입니다.

OG Violet

친근하고 콘텐츠 중심의 인상을 강화한 방향입니다.

02 / CONCEPT

내 정보 대표 화면 5종

리뉴얼 기획서의 정보 구조를 기준으로 시각적 위계와 화면 성격을 다르게 구성했습니다. 기능 범위는 같고 표현 방식만 비교할 수 있도록 맞췄습니다.

01

기본형

현재 카드 구조를 정돈하고 3분할 마일리지와 2×3 메뉴를 적용한 방향입니다.

02

브랜드형

짙은 헤더와 Primary 표식으로 OG의 존재감을 높인 방향입니다.

03

캐릭터형

신규 마스코트 선택을 내 정보의 중심 경험으로 배치한 방향입니다.

04

활동형

최근 방문과 마일리지 변동을 강조해 다음 행동으로 연결하는 방향입니다.

05

미니멀형

카드를 최소화하고 선과 여백으로 정보를 구분한 방향입니다.

03 / SYSTEM

두 앱에 공통 적용할 디자인 기준

유저앱만 먼저 리뉴얼하더라도 컬러·폰트·간격·아이콘의 기본 언어는 점주앱과 동일하게 유지합니다.

TYPOGRAPHY

Pretendard

제목·본문·레이블·설명 역할별 크기와 행간을 고정합니다.

SPACING

4px 기본 단위

화면 안쪽 여백과 요소 사이 간격을 일정한 단계로 사용합니다.

SHAPE

6 · 10 · 16 · 24px

컨트롤과 카드, 바텀시트의 크기에 따라 모서리 단계를 구분합니다.

ICON

기존 Material Icons 유지

아이콘 체계가 결정되기 전에는 현재 아이콘을 유지하고 크기와 색상만 통일합니다.

04 / FLUTTER

현재 앱 구조에 적용 가능한 기준

기존 기능을 유지하며 디자인을 단계적으로 적용할 수 있습니다.

두 앱 모두 Material 3와 Pretendard를 사용하고 있어 ColorScheme·TextTheme·컴포넌트 Theme를 확장하는 방식으로 적용할 수 있습니다.

공통 적용

컬러·타입·간격·모서리·버튼·입력·선택 상태와 오버레이의 시각 규칙

유저앱 전용

하단 5탭·중앙 바코드·Q오더·퀵적립·마일리지·커뮤니티 화면 구조

점주앱 전용

매장 운영·예약·웨이팅·Q오더 상태 카드와 점주용 내비게이션

적용 원칙

기능 로직과 API 호출은 유지하고 전역 Theme와 화면 스타일을 순차적으로 교체

05 / DECISION

이번 단계에서 결정이 필요한 항목

DECISION 01

Primary 컬러

OG Blue·OG Indigo·OG Violet 중 향후 두 앱에 공통으로 적용할 기준 컬러를 선택합니다.

DECISION 02

화면 컨셉

기본형·브랜드형·캐릭터형·활동형·미니멀형 중 전체 리뉴얼에 확장할 방향을 선택합니다.

컬러와 컨셉 확정 후 버튼·인풋 등 세부 컴포넌트와 전체 앱 화면 디자인을 해당 기준으로 진행합니다.
