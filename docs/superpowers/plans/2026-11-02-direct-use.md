# 바로사용 시안 구현 계획

**Goal:** 11/2 디자인 요청서의 상세 진입·금액 선택·점주에게 보여주는 사용 확인·만료 상태를 기존 사이트에 추가한다.
**Architecture:** 기존 매장 상세와 공통 버튼을 재사용하고, 별도 정적 시안 모듈을 홈 하위 메뉴에 연결한다. 기존 시안은 변경하지 않는다.
**Tech Stack:** ES modules, CSS, node:test, Playwright.
**Spec:** 11/2 정경진 첨부 `마일리지_바로사용_기능_디자인_요청서.pdf` 및 윤이사 최종 결정.

- [x] 회귀 테스트: 기존 상세 유지, 5,000M 단위, 확인/만료 동일 거래, 신규 메뉴 연결.
- [x] 상세 첫 화면 기존/반영 비교, 휠 선택, 확인/만료/동기화 지연 예시 구현.
- [x] 모바일/데스크톱 렌더링, 사진 카운터 겹침, 공통 버튼, 빌드 검증.
- [x] 사용자 검토 대기 문서 작성. 커밋·푸시·배포·Figma·앱 수정 제외.

## 결정 및 제약
- 개발 브랜치의 사진 위 바로사용 버튼과 기본 번개 아이콘을 참고한다. 바로적립 자산과 혼용하지 않는다.
- 요청서의 승인 화면은 사용 완료 후 점주에게 보여주는 화면이다. 점주 승인 버튼을 추가하지 않는다.
- 500m 이내, 최소/단위 5,000M, 별도 사용 한도와 매장별 허용 스위치는 추가하지 않는다.
- 확인 제한 3분 만료는 차감 취소/환불이 아니다. 만료 화면은 확인·닫기만 제공한다.
- 동기화 지연 화면은 서버 확인 완료로 표시하지 않는다.
- 시안은 정적이다. 금액·시간·번호는 예시이며 보안 애니메이션도 멈춘 한 장면으로 표현한다.
- 잔여값은 사용 가능 금액 기준임을 명시하고 보유 총액과 혼동하지 않는다.

- [x] 공통 요소 보완: 실제 bolt_rounded 글리프, 공통 뒤로가기, 사용 가능 금액 요약 적용 및 재검증.

- [x] 사용자 추가 요청: 진입 버튼 두 안 비교 정리와 검토용 2페이지 PDF 생성.
- 사용자 추가 요청으로 커밋·푸시 허용. 시안의 사용자 검토 대기 상태는 유지.
