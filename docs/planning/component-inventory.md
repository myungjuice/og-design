# 오지플랫폼 디자인시스템 제작 목록

업데이트: 2026-09-18

## 시안 표시 방식

- 시안 속 앱 기능은 실행하지 않습니다. 기본·선택·열림·오류 등 상태를 각각 펼쳐 표시합니다.
- 클릭·입력·호버를 해야만 보이는 예시와 상태 선택용 드롭다운은 사용하지 않습니다.
- 캔버스 이동·확대·보드 이동, AI 프롬프트 열기·복사는 열람 도구로 유지합니다.
- 동작 설명은 디자인 상태를 이해하는 데 필요한 내용으로 제한합니다.
- HTML의 inert는 예시를 조작하지 못하게 하는 캔버스 장치이며, 앱의 비활성 디자인을 뜻하지 않습니다.

## 집계 기준

- 기본 스타일: 캔버스 9개 보드.
- 기본 컴포넌트: 25개 묶음 중 25개 작성, 미작성 0개. 아이콘 버튼의 즐겨찾기와 용도별 배지 변형을 포함합니다.
- 앱 전용 조합: 26개 묶음. 2개 보완 중, 24개 미착수. 모두 완료 집계에서는 제외합니다.
- 캐릭터 선택 1개 묶음은 별도 보류합니다. 현재 프로필 이미지를 유지합니다.
- 보드 개수와 컴포넌트 개수는 다릅니다. 현재 캔버스는 기본 스타일 9개와 컴포넌트 20개, 총 29개 보드입니다.
- 한 묶음은 재사용할 구성요소의 단위이며 화면 수가 아닙니다. 실제 페이지 디자인은 별도 단계입니다.

## 디자인 방향

밝은 블루와 화이트를 기본으로 하고, 사용 가능 금액과 게이지에 브랜드 그라데이션을 사용합니다.
카드와 메뉴 타일에는 밝은 윗면, 얇은 가장자리, 짧고 부드러운 그림자로 입체감을 줍니다.
빛 방향은 통일하되, 카드와 조작 요소의 그림자 강도를 모두 같게 만들지는 않습니다.
기존 내 정보 시안과 공유 PDF는 이 목록 정리 작업으로 변경하지 않습니다.

## 4. 마일리지 표시 기준

- 사용 가능 / 총 보유 / 공유 적립의 3분할.
- 사용 가능 금액에 숫자용 브랜드 그라데이션 적용.
- 사용 가능 = floor(총 보유 / 5,000) × 5,000.
- 바 끝값 = max(5,000, ceil(총 보유 / 5,000) × 5,000).
- 16,000 M 예시: 사용 가능 15,000 M, 추가 보유 구간 1,000 M, 끝값 20,000 M. 비율 75% / 5% / 20%.
- 15,000 M처럼 정확한 배수는 끝값도 15,000 M이며 100%로 표시.
- 0 M은 0~5,000 M의 빈 바. 불러오는 중에는 —로 표시.
- 공유 적립은 별도 요약값이며 게이지에 더하지 않음.
- 8px 높이의 얇은 바. 숫자는 밖에 표시하고, 하단 반복 범례는 넣지 않음.
- 큰 금액·글자 확대의 조합 검토는 P05 마무리 단계에 포함.

## 공통 스타일 보완

- 정보 아이콘·닫기·텍스트 버튼은 `components/shared.css`를 재사용합니다.
- 각 컴포넌트는 공통 스타일을 가져오며, 프롬프트에도 동일한 CSS를 포함합니다.
- 같은 수준의 섹션 간격은 32px, 상태 비교 간격은 16px로 맞춥니다.
- 시간·첨부 문구의 행간은 타이포 토큰을 사용합니다.
- 툴팁 메시지는 정보 아이콘 왼쪽에 맞추고, 아이콘 아래 8px 간격으로 표시합니다.

## 6. 캔버스와 AI 전달

- 캔버스는 열람용이며 드래그 이동·줌·보드 이동을 제공.
- 기본 스타일과 컴포넌트의 영역 배경은 모든 보드를 포함하도록 자동 확장.
- 각 보드 전체 및 세부 예시에 AI 프롬프트 버튼 제공.
- 프롬프트에 현재 토큰 값, 공통 CSS, 상태·행동, Flutter 대응, 원본 위치 포함.
- 이미지와 HTML 전체는 텍스트 복사에 포함하지 않음. 참고 이미지는 별도 첨부.
- 문구·CSS·프롬프트가 서로 다른 규칙을 안내하지 않도록 함께 검토.
- 테스트는 상태별 표시, 예시 조작 차단, 보드 배치, 프롬프트 복사와 모바일 열람을 확인.

## 공통 코드 재사용 구조 · 2026-09-18

기본 25종은 components/*/render.mjs에서 HTML을 생성하고 기존 컴포넌트 CSS를 함께 사용합니다.
캔버스는 같은 원본을 import해 설명과 정적 상태 예시를 배치합니다.
새 화면은 components/index.mjs와 index.css를 가져와 조합합니다.
입력 변형, 다이얼로그·시트 내부 버튼, 카드 표면도 공통 원본에 연결했습니다.
사용법: [공통 컴포넌트 사용법](../../design-system/components/README.md).
기존 concepts/my-info는 이전 시안으로 유지하며 이번 공통화에 연결하지 않았습니다.
이 구조 변경은 앱 전용 조합 26개의 완료 수에는 포함하지 않습니다.
