# 바로사용 · A안 확정 / 번호 강조안 검토

상태: 진입 버튼 A안은 사용자 확정. 금액 선택·번호 강조 비교안과 후속 상태는 사용자 검토 대기다. 커밋·푸시는 디자인 전체 승인을 뜻하지 않는다.

## 근거
- 11/2 정경진 Slack 디자인 요청서: 매장 상세 사진 위 진입, 금액 휠 선택, 점주에게 보여주는 사용 완료 화면, 확인 만료 상태.
- 윤이사 최종 결정: 매장 500m 이내, 별도 사용 한도 없음, 매장별 허용 스위치 없음, 지도 하단 요약 카드 추가 안 함.
- 11/3 사용자 결정: A안 확정, 확인번호 자리별 표시, 번호 강조·금액 축소 비교안 추가.
- 사용자 전달 피드백: 연결 상태는 30초 주기로 갱신하며 거래 자체에 영향을 주지 않는다. 서버 시각은 생략 가능한 제안이며 최종 정책 변경으로 처리하지 않는다.

## 현재 검토 화면
1. `/v2/home/#direct-use-entry`: 확정된 A안 캡슐형. 페이지네이션 우측 상단(배경만 불투명도 50%), 바로사용 버튼 우측 하단(오른쪽·아래 16px).
2. `/v2/home/#direct-use-amount`: 매장명 강조, 최소 5,000M·5,000M 단위 휠, 보유/사용 가능/사용 후 사용 가능 금액 구분.
3. `/v2/home/#direct-use-confirm`: 기존 완료 화면과 번호 강조안 비교. 아래에서 번호 강조안의 확인 만료·연결 지연 상태도 비교한다.

총 6개 정적 시안이다. 실제 차감·위치 확인·서버 통신·카운트다운·보안 애니메이션은 실행하지 않는다. 시간·번호·금액은 배치용 예시다.

## 번호 강조안
- 확인번호를 4칸으로 나눠 가장 크게 표시한다.
- 사용 금액은 보라/회색 박스 밖 하단 사용 내역으로 옮긴다.
- `서버 확인됨` 등 연결 상태 문구와 남은 확인 시간은 유지한다.
- 강조안에서만 박스 하단 `현재 시각` 줄을 생략한다. 하단 `사용 일시`는 거래 시각으로 계속 표시한다.
- 연결 지연에는 완료된 사용 박스를 유지하고 보조 상태 문구만 구분한다. 만료·거래 실패처럼 표시하지 않는다.
- 확인 화면 만료는 사용 취소/자동 환불이 아니다. 만료·연결 지연에 새 차감 CTA를 두지 않는다.

## 예시 일관성
- 현재 사용 가능 190,000M / 보유 192,000M / 사용 10,000M / 사용 후 사용 가능 180,000M.
- 확인번호 4368, 사용 일시 2026.11.02 15:30:05.
- 기존 정상안 현재 시각 15:30:32, 남은 확인 시간 2:33.
- 만료안은 0:00, 연결 지연안은 남은 시간 확인 중으로 표시한다.

## 공통 요소와 보존
- 앱 개발 브랜치의 기본 Material `Icons.bolt_rounded`와 공통 버튼·아이콘 버튼 렌더러를 사용한다. 전용 수령 바로사용 이미지가 아니다.
- 번개 글리프 SVG와 출처/라이선스는 `assets/material/`에 보존한다.
- 기존 매장 상세는 `/v2/home/#store`에 유지한다.
- B안 원형 렌더러와 이전 공유 PDF는 보존한다. 현재 화면에서는 확정된 A안만 표시한다.
- 기존 완료안은 비교 기준으로 유지하고, 번호 강조안과 후속 상태만 새 제안으로 둔다.
