## 근거
- 2026.11.02 정경진 Slack 디자인 요청서: 매장 상세 사진 위 진입, 금액 휠 선택, 점주 확인용 사용 완료 화면, 만료 상태.
- 윤이사 최종 결정: 매장 500m 이내, 별도 사용 한도 없음, 매장별 허용 스위치 없음, 지도 하단 요약 카드 추가 안 함.
- 개발 브랜치 `origin/feature/OGPLA-99-오지고랜드-마일리지-바로사용-ui-ux-구현`의 `shop_contents.dart`: 사진 위 버튼 및 기본 Material `Icons.bolt_rounded` 사용. 전용 수령 이미지로 보지 않는다.

## 검토할 화면
1. `/v2/home/#direct-use-entry`: A안 캡슐형 / B안 원형 두 안을 나란히 비교. 사진 장수 카운터와 분리. 기존 상세는 `/v2/home/#store`에 보존.
2. `/v2/home/#direct-use-amount`: 매장명 강조, 최소 5,000M·5,000M 단위 휠, 보유/사용 가능/사용 후 사용 가능 금액 구분.
3. `/v2/home/#direct-use-confirm`: 사용 완료·3분 만료·연결 지연 비교. 점주가 직접 승인하는 흐름은 추가하지 않음.

버튼 2안 + 금액 선택 1개 + 확인 3개 = 총 6개 정적 시안. 실제 차감·위치 확인·서버 통신·카운트다운은 실행하지 않는다. 보안 파동도 정지 장면이다.

## 예시 일관성
- 현재 사용 가능 190,000M / 보유 192,000M / 사용 10,000M / 사용 후 사용 가능 180,000M.
- 동일 거래의 확인 번호 4368, 사용 15:30:05, 정상 15:30:32(잔여 2:33), 만료 15:33:05(잔여 0:00).
- 확인 화면 만료는 사용 취소/자동 환불이 아니다. 만료·연결 지연에 새 사용 CTA를 두지 않았다.
- 연결 지연에는 서버 확인 완료 표시와 확정 잔여 시간을 사용하지 않았다.

## 검증
- 전체 단위 테스트 520개 통과.
- 브라우저 검증 통과: 375/768/1600px, 새 링크·기존 매장 링크, 가로 넘침·푸터 겹침·사진 카운터 겹침.
- 실제 캡처 검토: 진입·금액·정상·만료·연결 지연.
- 별도 코드 리뷰: 수정 필요 사항 없음. 리뷰어 자체 브라우저는 권한 제한으로 실행하지 못했고, 렌더링 검증은 주 실행자의 브라우저로 수행.

사용자 추가 요청에 따라 사이트 변경을 커밋·푸시한다. 별도 배포, Figma·Flutter 앱 수정은 이번 작업 범위에 포함하지 않는다.

## 공통 요소 적용 보완
- 진입 버튼의 임시 번개 윤곽을 앱에서 쓰는 실제 Material `bolt_rounded` 글리프의 SVG로 교체했다. 원본 폰트의 라이선스와 출처를 `assets/material/LICENSE.html`에 동봉했다.
- 금액·확인 화면의 뒤로가기를 공통 iconButton 렌더러와 48px 터치 크기로 통일했다.
- 금액 요약의 중간 행을 현재 사용 가능 금액으로 명시해 보유 총액에서 직접 계산한 값으로 오해하지 않도록 했다.

## 바로적립 계열 제안
- 사용자 의견에 따라 원형 보라 버튼, 내부 명암, 좌측 상단 광택을 바로적립과 맞춘 비교안을 추가했다.
- 바로적립의 M/적립 문구가 포함된 글리프는 재사용하지 않고 번개 + 바로사용으로 구분했다.
- 원형은 사용자 검토용 제안이며 수령한 확정 바로사용 디자인으로 표시하지 않는다. 이전 캡슐형도 보존한다.
